# [120](https://darknetdiaries.com/transcript/120/). Voulnet

When looking at a malware executable, find human-readable text in it. This will give you clues for what it does.

> One technique for analyzing malware is to run the command ‘strings’ on it.  This will search the malware for any human-readable words, and it just spits out a list of words for you to see.  This might give you some clues as to what’s going on, like any internal notes left in the code.

The FBI will sometimes [open malware in Notepad], print out the compiled code, and ask their creators if they recognize it, which they might from the human-readable strings embedded in it.
