# [100](https://darknetdiaries.com/transcript/100/). NSO

Security researcher John Scott-Railton once clicked a malicious link and observed a remote jailbreak of his iPhone.

> When a user clicks the link, a JavaScript program runs.  That JavaScript program tries to exploit a bug in WebKit which would allow it to write data to the phone.  Through this bug and WebKit, the JavaScript program downloads a malicious program.

The reason it needs to jailbreak the phone is because Apple won't let any unapproved executable run.

> The malicious program that was just downloaded cannot execute unless the iPhone is jailbroken.

Apple approves every single executable that can run on an iPhone. But that didn't stop Pegasus.

> The malware uses an exploit to jailbreak the iPhone which allows it to run any app that’s on the phone, not just the ones downloaded through the App Store.

If your phone is infected with Pegasus, the data on your phone is available to an attacker.
