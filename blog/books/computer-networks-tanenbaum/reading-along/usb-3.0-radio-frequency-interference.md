# [USB 3.0 Radio Frequency Interference](https://www.usb.org/document-library/usb-30-radio-frequency-interference-impact-24-ghz-wireless-devices)

If a wireless mouse dongle is near an active USB3 port, there will be a lagging response to mouse movement.

![17449869656552819088308204859055](https://github.com/user-attachments/assets/dba77a4a-3632-4ba2-9a9e-566ac8f35c2f)

This is because the USB3 device, cable, and port all emit radio noise which interferes with the data transmission between the mouse and the dongle.

![17449869887985745412329321229807](https://github.com/user-attachments/assets/57ef5a04-805e-42ef-8151-a4f783c3be57)

Shielding can significantly reduce the interference, especially if both the connector and all exposed PCB area is shielded.

![17449870101986471632173903815119](https://github.com/user-attachments/assets/e16d9b35-7a7a-4482-ac40-d6181668cb10)

![17449870259973296832267210070843](https://github.com/user-attachments/assets/d5bc3bf9-c070-41fa-bb50-fd1913834e18)

Another strategy to improve the performance of the Bluetooth mouse is to move its dongle away from the active USB3 port via a USB extension cable.

![17449870420475578962811268535249](https://github.com/user-attachments/assets/93686664-053c-44b4-9450-ea5566ce1049)
